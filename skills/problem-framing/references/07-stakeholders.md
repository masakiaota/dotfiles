# 関係者が複数いる場合

出典：『ライト、ついてますか』第18章。おもちゃ工場の費用削減の話を要約する。

## 費用を下げたい人と工場を残したい人

- **当初の捉え方**：副社長たちは、3工場から商品を出荷する費用を減らしたいと相談する。担当者は生産と配送の最適化として受け取る。
- **展開**：費用を調べると、最も効率のよい工場に生産を集める案が浮かぶ。しかし、社長と会長はほかの工場の近くに住んでおり、移るつもりがなかった。
- **結果**：副社長たちはその事情を知っていた。計算機の答えなら社長と会長を説得できるかもしれないと期待していたが、計算結果だけで彼らの意向を変えるのは難しいと認める。

## この項目で捉えること

依頼する人、決定する人、結果の影響を受ける人の望みを分ける。この話では、費用削減と生活拠点の維持が衝突していた。誰が何を受け入れられるかまで含めて、実行可能な方針を考える。
