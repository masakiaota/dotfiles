# 理解と仮定を検証する

出典：『ライト、ついてますか』第6章。入札計算が終わった後の話を要約する。

## 他社の入札額は固定されているか

- **当初の捉え方**：ある会社は、入手した他社の秘密の入札額を使って、自社の入札を有利に変更しようとした。担当者は、その条件で計算を解いた。
- **展開**：後に担当者は、別の会社も同様の計算を頼んでいたと知る。他社も入札を変えるなら、計算の前提にした金額が変わり得ると気づいた。
- **結果**：担当者は、情報が相手を誘導するためのものだった可能性まで考え直す。これらは彼の推測であり、実際の落札結果として確認された話ではない。

## この項目で捉えること

与えられた条件で答えが出ても、その条件が現実に保たれるかは別に確かめる。確認した事実と仮説を分け、新しい情報が方針に影響するなら前提を更新する。
