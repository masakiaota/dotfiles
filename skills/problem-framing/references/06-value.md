# 解決する価値を確かめる

出典：『ライト、ついてますか』第20章。外交暗号の解読任務の話を要約する。

## 解読できた情報の価値

- **当初の捉え方**：暗号の専門家は、同盟国の外交暗号を解く任務に取り組む。難しい暗号を解くことに長期間、力を注いだ。
- **展開**：2年以上かけて暗号の鍵になる本を突き止め、緊急度が高いと思われる通信から解読した。
- **結果**：解読した57件はすべて経費勘定だった。専門家は失望し、その後、機関を辞めて教師になった。

## この項目で捉えること

技術的に解けたことと、得られた結果に価値があることを分けて考える。大きな労力を投じるときは、その結果が何に役立つのか、期待を支える根拠があるかを確かめる。
