# 解くべき問題を特定する

出典：『ライト、ついてますか』第1〜3章。エレベーターへの苦情の話を要約する。

## エレベーターの遅さと利用者の不満

- **当初の捉え方**：エレベーターが遅いという苦情に対し、増設や運行方法の変更など、利用者の待ち時間を減らす案が浮かぶ。
- **展開**：利用者は通勤の手間やいらだちを減らしたい。所有者は苦情をなくしたい。同じ状況でも、誰の望みを扱うかで解決案が変わる。
- **結果**：待つ場所に鏡を置くと、利用者の注意が鏡に向き、苦情はいったん消える。その後、落書きなど別の問題が生じる。

## この項目で捉えること

現状と、当事者が望む状態との差を具体化する。この話では、実際の待ち時間、待つ間のいらだち、所有者に届く苦情は別々の対象である。誰のどの状態を変えるかによって、成功の確かめ方も変わる。
