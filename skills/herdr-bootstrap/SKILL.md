# Herdr 操作の開始

Herdr を操作する前に、公式スキルを読む。

1. `test "${HERDR_ENV:-}" = 1` を実行する。
2. 失敗した場合は、Herdr 管理下のペインからは操作できないと伝え、Herdr の制御コマンドを実行しない。
3. 成功した場合は `herdr --skill` を実行し、出力全体を読む。
4. 以後の操作は、読み取った公式スキルに従う。

公式スキルの本文はこのスキルへ複製しない。`herdr --skill` を正本として扱う。
